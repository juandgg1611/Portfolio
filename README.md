# Juan Oberto - Portafolio Personal / Personal Portfolio

*Read this in [English](#english) | Lee esto en [Español](#español)*

---

## Español

El portafolio personal de **Juan Oberto**. Desarrollado con Next.js 15, React, TailwindCSS, GSAP y Lenis. Cuenta con animaciones basadas en scroll, transiciones de página fluidas, y un diseño premium optimizado.

### Características

- Animaciones de scroll mediante GSAP y ScrollTrigger.
- Scrolling suave gracias a Lenis.
- Transiciones de página animadas con next-transition-router.
- Cursor personalizado e interactivo.
- Diseño responsive y adaptativo.
- Totalmente tipado usando TypeScript.

### Instalación

```bash
npm install
npm run dev
```

## English

The personal portfolio of **Juan Oberto**. Built with Next.js 15, React, TailwindCSS, GSAP, and Lenis. It features scroll-driven animations, smooth page transitions, and a premium optimized design.

### Features

- Scroll-driven animations using GSAP and ScrollTrigger.
- Smooth scrolling powered by Lenis.
- Animated page transitions using next-transition-router.
- Interactive custom cursor.
- Responsive and adaptive design.
- Fully typed with TypeScript.

### Installation

```bash
npm install
npm run dev
```
