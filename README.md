# Juan Oberto - Portafolio Personal

El portafolio personal de **Juan Oberto**. Desarrollado con Next.js 15, React, TailwindCSS, GSAP y Lenis. Cuenta con animaciones basadas en scroll, transiciones de página fluidas, y un diseño premium optimizado.

## Características

- Animaciones de scroll mediante GSAP y ScrollTrigger.
- Scrolling suave gracias a Lenis.
- Transiciones de página animadas con next-transition-router.
- Cursor personalizado e interactivo.
- Diseño responsive y adaptativo.
- Totalmente tipado usando TypeScript.

## Instalación

```bash
npm install
npm run dev
```
